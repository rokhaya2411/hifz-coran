HIFZ • Lire & mémoriser le Coran

CONTENU
- Lecture des 114 sourates
- Texte arabe
- Traduction française
- Audio de récitation
- Recherche dans la traduction de la sourate ouverte
- Mode mémorisation avec texte flouté
- Statuts : À apprendre / À réviser / Mémorisé
- Révision
- Progression
- Mode sombre
- Sauvegarde locale dans le navigateur

LANCEMENT
1. Décompresse le ZIP.
2. Ouvre index.html dans Chrome ou Edge.
3. Une connexion Internet est nécessaire pour charger le texte, la traduction et les audios.

DONNÉES
L'application utilise l'API Al Quran Cloud pour le contenu et l'audio. La documentation indique notamment l'endpoint /surah/{number}/{edition}, et son CDN fournit des récitations audio. 
Références : https://alquran.cloud/api
https://legacy.alquran.cloud/cdn

IMPORTANT
La progression est enregistrée uniquement sur cet appareil/navigateur via localStorage.
Pour une vraie application Android/iPhone avec compte utilisateur, synchronisation cloud, notifications et installation Play Store/App Store, il faudra ensuite transformer cette version en application mobile et ajouter un backend.
